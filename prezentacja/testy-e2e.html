Testy E2E w modelu Page Object Model

Mateusz Krzyzak · API i automatyzacja · ← powrót do strony głównej

12 testów E2E w przeglądarce Chrome. Każda strona aplikacji ma klasę z lokatorami i akcjami (Page Object), a test zawiera wyłącznie scenariusz i asercje. Zmiana interfejsu wymaga poprawki tylko w klasie strony.

Obiekty stron

KlasaStronaElementy i akcje
HomePagestrona głównaopen(), roomHeading(), roomPrice(), bookLink(), setDates(), checkAvailability()
ContactFormformularz kontaktowypola, fill(), submit() (zapis odpowiedzi do evidence), errors, confirmation()
ReservationPagerezerwacja pokojuopen(room, checkin, checkout), priceLine(), total(), fillGuest(), submitBooking()
AdminLoginPagepanel administratoraopen(), fill(user, pass), submit(), error
  • Fixture pages/index.ts rozszerza fixture warstwy API – test E2E ma jednocześnie obiekty stron i klientów API (np. sprawdzenie szczegółów pokoju przez API przed testem rezerwacji).
  • Screeny kroków: a.step(page, opis, [elementy]) zapisuje wycinek obejmujący wskazane elementy.
